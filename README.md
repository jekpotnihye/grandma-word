One word a grandma would text about AI: the typo she would actually make
trying to name the chatbot she keeps hearing about.

Run `node main.ts` (Node 22+). It writes the single word to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
